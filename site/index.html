Nothing runs behind your back

Nothing changes your files until you say go.

Before each step, Claude says in one sentence what it will do. Steps that only read run straight away. Steps that write ask first.

Reads only

Looks at your code or your idea and reports back. Nothing on disk changes, so it runs the moment you reach it. Grilling and review work this way.

Changes files

Writes code, edits files or creates tickets. It states the change first and waits for your go. Spec, tickets and build work this way.

House rules

Rules it follows in every project.

Every skill follows these. If your project's CLAUDE.md says otherwise, yours wins.

Design

No AI look

No purple gradients, glowing borders or floating card shadows.

Design

Not everything in threes

Variable column spans, side-aligned headlines and dense tables instead.

Design

A 4px grid

Every padding, margin and gap is a multiple of four pixels.

Design

One bold thing per screen

One statement element. Everything else stays quiet.

Copy

Banned words

"Seamless", "supercharge" and the rest of the slop never ship.

Copy

Specifics over hype

"Exports in 2 seconds", not "Blazing fast".

Setup

Install once. Then type /start.

Pick where you use Claude. Each takes under a minute.

Claude app

Phone, web or desktop

  1. Open Customize → Plugins.
  2. Tap Add, then Add marketplace, and enter the name below.
  3. Find frontier under Discover and tap Add.
bgordon01/frontier

Claude Code

Run it in the terminal

Paste this inside a Claude Code session.

/plugin install frontier --marketplace bgordon01/frontier

Cloud sessions

Add it to your setup script

Paste this once into your environment's Setup script.

#!/bin/bash
curl -fsSL https://raw.githubusercontent.com/bgordon01/frontier/main/install.sh | bash || true

Upgrading from claude-toolkit? Remove toolkit and add frontier. For a Mac install script, see the README.
