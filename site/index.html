Claude app

Phone, web or desktop. Most people start here.

  1. Open Customize → Plugins.
  2. Tap Add, then Add marketplace, and enter:
bgordon01/claude-toolkit
  1. Find toolkit under Discover and tap Add.

Claude Code

Run this inside Claude Code.

/plugin install toolkit --marketplace bgordon01/claude-toolkit

Cloud coding sessions

Paste once into your environment's Setup script.

#!/bin/bash
curl -fsSL https://raw.githubusercontent.com/bgordon01/claude-toolkit/main/install.sh | bash || true

The plugin is still listed as toolkit while the Frontier name rolls out. For a Mac install script with shorter commands, see the README.
