The six steps, in order. Steps that change files stop and wait for you to press Go. Tap any step to read it.

Start

Prompting and hoping goes in circles.

You prompt, Claude writes 400 lines, something breaks, you prompt again. Frontier puts a plan, a test and a review in front of every change.

Without a plan

Every fix is a guess.

With Frontier

Every change traces back to a decision you made.

Nothing changes your files until you say go.

Before each step, Claude tells you in one sentence what it will do. Steps that only read run straight away. Steps that write ask first.

  • Reads onlyLooks at your code or idea and reports back. Runs straight away.
  • Changes filesWrites code, edits files or creates tickets. Waits for your go.

Other ways in.

Four shortcuts start somewhere other than Grill, then join the main steps where they fit.

Improve an existing project

/improve-codebase-architecture or /impeccable critique lists what's worth fixing. Changes nothing.

Then continues at Tickets

Fix a bug

/diagnosing-bugs finds the cause first, then fixes it test-first.

Then continues at Review

Write or improve copy

/copywriting, /copy-editing, then /stop-slop.

Works on its own

Design something optional

/impeccable shape writes a design brief before anything is drawn. Once screens exist, /impeccable critique and one steer set the look, and /impeccable document records it in DESIGN.md.

Then continues at Spec

Install once. Then type /start.

Pick where you use Claude. Each takes under a minute.

Claude app

Phone, web or desktop.

  1. Open Customize → Plugins.
  2. Tap Add, then Add marketplace, and enter:
bgordon01/frontier
  1. Find frontier under Discover and tap Add.

Claude Code

Run this inside Claude Code.

/plugin install frontier --marketplace bgordon01/frontier

Cloud coding sessions

Paste once into your environment's Setup script.

#!/bin/bash
curl -fsSL https://raw.githubusercontent.com/bgordon01/frontier/main/install.sh | bash || true

Upgrading from claude-toolkit? Remove toolkit and add frontier. For a Mac install script, see the README.
